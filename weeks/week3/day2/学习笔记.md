# mutex

### 常见用法
创建mutex
```cpp
std::mutex mtx;
```

使用mutex
```cpp
mtx.lock();
mtx.unlock();
```

### 进阶用法 - lock_guard
实际开发中，在复杂业务场景容易忘记解锁mutex，因此不推荐手动使用mutex，而是使用lock_guard来自动管理
```cpp
{
    // 手动开辟一个作用域控制释放时机
    std::lock_guard<std::mutex> lock(mtx); // 代替 mtx.lock(); 临界区 mtx.unlock();
    // 临界区
    // 作用域结束自动解锁
}
```
