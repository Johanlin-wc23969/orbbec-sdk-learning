# 总结博客

### 多线程 & 互斥锁 & 条件变量
通过` std::thread(func, params) `创建线程，允许同一时间内多个任务并发执行。在实际开发中，多个任务经常同时访问同一个变量也就是共享内存，如果多个线程同时修改和读取这个变量就会造成数据不一致的问题，我们称之为数据竞争。为了解决这个问题，我们允许多个线程并发执行，但是当访问共享变量的时候必须串行化也就是必须遵循先后顺序，因此我们引入了互斥锁机制。我们给变量设置了一个同时只能有一个线程访问的范围-临界区，为了实现单线程访问，每个线程在访问临界区数据时必须先拿到互斥锁，在结束时释放锁来允许下一个排队的线程获取互斥锁。

举个例子：
```cpp
#include <thread>

void worker(int& count, std::mutex& mtx){
    for(int i = 0; i < 10; i++){
        mtx.lock();
        count++;
        mtx.unlock();
    }
}
int main(){
    int count = 0;
    std::mutex mtx;
    std::jthread t1(worker, std::ref(count), std::ref(mtx));
    std::jthread t2(worker, std::ref(count), std::ref(mtx));

    std::cout << "count = " << count << "\n";

    return 0;
}
```

#### 互斥锁忘记释放？？？
在复杂的开发场景中，在多线程使用互斥锁，我们会经常忘记释放锁，导致其他线程永远在等待，无法访问临界区。因此在实际开发中，推荐使用 ` std::lock_guard<std::mutex> lock `, 他会管理锁的周期，出作用域后自动释放锁。

拿上一个例子来说，我们用` std::lock_guard<std::mutex> lock ` 代替 ` mtx.lock() & mtx.unlcok() `, 并且可以手动设置作用域控制锁的释放时机：
```cpp
void worker(int& count, std::mutex& mtx){
    for(int i = 0; i < 10; i++){
        {
            std::lock_guard<std::mutex> lock(mtx);
            count++;
        }
    }
}
int main(){
    int count = 0;
    std::mutex mtx;
    std::jthread t1(worker, std::ref(count), std::ref(mtx));
    std::jthread t2(worker, std::ref(count), std::ref(mtx));

    std::cout << "count = " << count << "\n";

    return 0;
}
```
#### 线程怎么排队等待互斥锁？？？
当多线程尝试获取锁，而锁正在被占用时，线程通常需要等待，而等待的方式有两种，一种是忙等待，一种是线程睡眠。忙等待是不推荐的等待方式，因为他会造成100%的CPU占用率，因此让线程睡眠是主流的方案。当互斥锁被占用。操作系统会让线程阻塞并沉睡，直到锁被释放，唤醒等待的一个线程。

### 条件变量 condition variable
条件变量机制是用来控制互斥锁的释放和线程的唤醒，在以资源作为线程任务执行的核心，我们需要判断当前线程是否满足执行任务的条件，再决定是否占用互斥锁。如果当线程占用互斥锁，却不满足执行任务的条件，当前线程应当释放互斥锁沉睡，等待满足条件后被唤醒。重点：此时，线程的唤醒不依赖锁的释放（操作系统的互斥锁机制），而是依赖手动的唤醒` notify_one() `，线程唤醒后满足条件才会继续执行任务。根据这个机制，我们将线程分为两个种类，消费者线程和生产者线程，生产者负责资源的生产和消费者线程的唤醒，而消费者负责资源的消耗和等待条件满足（资源准备就绪）

举个例子：
```cpp
void consumer(std::queue<int>& q, std::mutex& mtx, std::condition_variable& cv){
    {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock,[&](){ return !q.empty();});
        int value = q.front();
        q.pop();
    }
}
void producer(std::queue<int>& q, std::mutex& mtx, std::condition_variable& cv){
    {
        std::lock_guard<std::mutex> lock(mtx);
        q.push(42);
    }
    cv.notify_one();
}
int main(){
    int count = 0;
    bool ready = false;
    std::mutex mtx;
    std::condition_variable cv;
    std::jthread t1(producer, std::ref(count), std::ref(ready), std::ref(mtx), std::ref(cv));
    std::jthread t2(consumer, std::ref(count), std::ref(ready), std::ref(mtx), std::ref(cv));

    std::cout << "count = " << count << "\n";

    return 0;
}
```

### async 异步执行
在实际开发过程中，我们有时候只是需要异步执行一个函数返回结果。而` std::thread `需要声明一个变量并传递引用获取结果，默认丢弃函数返回值。因此引入了` std::async() `
举个例子：
```cpp
int add(int a, int b){
    return a + b;
}
int main() {
    auto future = std::async(std::launch::async,add,10,20);
    int res = future.get(); // 任务还未完成时 处于阻塞状态
    std::cout << res;

    return 0;
}
```
#### 异步执行模式
```cpp
auto f1 = std::async(std::launch::async,func,params); // 立即执行
auto f2 = std::async(std::launch::deferred,func,params); // future.get()的时候再开始执行
```
#### 任务条件判断
获取future后，可以通过future了解任务的完成状态
```cpp
if(future.wait_for(std::chrono::seconds(10)) == std::future_status::ready)
```


### promise & future
在多线程场景中，我们对数据的写入和读取进行了独立拆分，用promise负责写入，future负责读取。这样我们可以只传入promise在多线程中获取结果，外部用future读取结果
std::promise<int> p;
std::future<int> f = p.get_future();
举个例子：
```cpp
void work(std::promise<int> p){
    p.set_value(100);
}
int main(){
    std::promise<int> p;
    std::future<int> f = p.get_future();
    std::jthread t1(work,std::move(p));
    std::cout << f.get() << "\n";

    return 0;
}

### std::future 只能get()访问一次
通常只能get()一次，多次get()访问结果会报错

为了允许多个消费者共享future，读取同一个结果, 多次使用get()，我们引入了 std::shared_future<int> 
```cpp
std::shared_future<int> sf1 = f.share(); 
```

| 需求           | 推荐工具                                |
| ------------ | ----------------------------------- |
| 简单启动线程       | `std::jthread`                      |
| 多线程共享复杂数据    | `std::mutex` + RAII 锁               |
| 等待某个条件成立     | `std::condition_variable`           |
| 异步执行并获取返回值   | `std::async` + `std::future`        |
| 跨线程手动设置结果    | `std::promise` + `std::future`      |
| 简单计数器/标志位    | `std::atomic`                       |
| 限制并发数量       | C++20 `std::counting_semaphore`     |
| 多线程统一起跑/等待完成 | C++20 `std::latch` / `std::barrier` |
