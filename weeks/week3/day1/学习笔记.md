# std::thread 
std::thread t(函数名，参数(可选))

### 创建线程
```cpp
void hello(){};
std::thread t(hello); // 创建线程
```

### 等待线程
```cpp
t.join(); // 等待t线程结束
```

### 线程分离
```cpp
t.detach(); // 主线程不需要等待子线程t结束
```

### Lambda线程
Lambda线程（主流）
```cpp
std::thread t([](){return std::cout << "Thread is running\n"});
```

### 线程默认只接受传递参数副本，而非引用
复制参数
```cpp
void func(int input){...};

int x = 10;
std::thread(func,x); // x = 10;
```
引用参数 需要额外使用std::ref
```cpp
void func(int& input){...};

int x = 10;
std::thread(func,std::ref(x)); // x = 11;
```

### 获取线程ID
```cpp
std::this_thread::get_id();
```

### 线程睡眠
```cpp
std::this_thread::sleep_for(std::chrono::seconds(10));
```

### 守护线程（不推荐用detach）
```cpp
std::thread(heartbeat).detach();
```

### 进阶版thread - std::jthread（推荐，避免手动join）
自动使用join()，不需要程序员手动join().
```cpp
std::jthread t(func);
```
