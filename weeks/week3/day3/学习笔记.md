# condition variable
条件变量用于生产者消费者模型，消费者需要等待生产者产生数据，而这个等待不能是忙等待，而是线程睡眠和唤醒机制

### 创建condition variable
```cpp
std::mutex mtx;
std::condition_variable cv;
bool ready = false;
```

### 消费者线程
```cpp
void consumer(){
    std::unique_lock<std::mutex> lock(mtx); // 必须使用unique_lock<> 因为wait内部需要配合它进行锁的释放和获取
    cv.wait(mtx,[]{return ready;});

    std::cout << "消费者\n";
}
```

### 生产者线程
```cpp
void producer(){
    {
        std::lock_guard<std::mutex> lock(mtx);
        ready = true;
    }
    std::cout << "生产者\n";
    cv.notify_one();
}
```

### 运行线程
```cpp
int main() {
    std::jthread t1(consumer);
    std::jthread t2(producer);

    return 0;
}

### 实际使用场景
生产者消费者模型
```cpp
std::unqiue_lock<std::mutex> lock(mtx);
cv.wait(lock,[]{return ready});
// 消费逻辑

std::lock_guard<std::mutex> lock(mtx);
// 生产逻辑
```

超时场景（数据库连接池，网络请求，任务队列）
```cpp
std::unique_lock<std::mutex> lock(mtx);
if(cv.wait_for(lock, std::choro::seconds(10), []{return ready})){
    std::cout << "准备完毕\n";
}else {
    std::cout << "已超时\n";
}
```

等到指定时间
```cpp
auto deadline = std::chrono::steady_clock::now() + 5s;
if(cv.wait_until(lock, deadline, []{return ready;})){
    std::cout << "准备完毕\n";
}else {
    std::cout << "已超时\n";
}
```
