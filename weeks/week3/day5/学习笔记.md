# promise
async的进阶版本，用于在线程之间传递数据。

主要分为两部分：一个线程负责写入数据，一个线程负责读取数据。
* promise（线程A） - 写入结果
* future（线程B）- 读取结果

# async vs promise
async的结果是固定从执行的函数中计算并通过返回的future.get()读取。（理解：封装了 promise + future + thread）
```cpp
// 内部高度封装了写入+读取+线程
auto future = std::async(std::launch::async,func());
auto res = future.get();
```
而promise细化了这个过程，允许创建底层的sharedState，通过promise对象手动写入数据，future手动读取数据，并且配合手动创建的线程。
```cpp
// 数据写入+读取的句柄
std::promise<int> p;
auto future = p.get_future();

// 创建线程执行任务
std::jthread t([p = std::move(p)]() mutable {
    // 写入结果
    p.set_value(42);
});

// 读取结果
auto res = future.get();
```

### promise 和 future 的使用流程
```CPP
线程A（生产者）
    |
std::promise
    |
std::future
    |
线程B（消费者）
```

### 创建promise
```cpp
std::promise<int> p;
std::future<int> future = p.get_future();
p.set_value(100);
std::cout << future.get() << std::endl;
```

### 多线程实例
```cpp
void worker(std::promise<int> &p){
    int result = 10 + 20;
    p.set_value(result);
}

int main() {
    std::promise<int> p;
    std::future<int> future = p.get_future();
    std::jthread t(worker,std::move(p));

    std::cout << "waiting...\n";
    auto res = future.get();
    std::cout << "res\n";

    return 0;
}
```
