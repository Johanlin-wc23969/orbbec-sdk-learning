# std::future & std::async()
std::thread 通常无法获取函数返回值，默认丢弃。因此，在使用std::thread的时候，我们会将变量作为参数在函数内部计算并赋值，并且在主线程使用join()等待，线程结束后再使用变量数值。为了能够获取返回值并且异步执行，当变量在异步还没计算出结果时阻塞，我们使用std::future和std::async();

# 实例
```cpp
int add(int a, int b){ return a+b;}

auto future = std::async(add,10,20);

// 如果async的add函数还没结束 会在此阻塞直到返回结果
std::cout << future.get() << std::endl;
```

### 检查任务状态
```cpp
auto future = std::async(add, 10, 20);
if(future.wait_for(std::chrono::seconds(10)) == std::future_status::ready){
    std::cout << "Done\n";
}else{
    std::cout << "Running\n";
}

// 状态类型
// future_status::ready
// future_status::timeout
// future_status::deferred
```

### launch策略
立即创建线程并执行
```cpp
// 立即开始
auto future = std::async(std::launch::async,add);
```
等到调用get()或者
```cpp
auto future = std::async(std::launch::deferred,add);
std::cout << "等待十秒\n";
std::cout << "等待十秒\n"; 
std::cout << "等待十秒\n"; 
std::cout << "等待十秒\n"; 
// 此时才开始创建线程执行add函数
auto result = future.get();
```

### std::thread vs std::async()
thread 是面向线程的，线程持续存在，不断获取并执行任务
async() 是面向结果的，只执行一次任务并获取结果
