# std::filesystem
cpp的文件系统用来方便的操作文件和目录

### 如何创建实例
```cpp
std::filesystem::path p("project/myText.txt")

std::cout << "文件路径：" << p << std::endl;
```

### 获取文件名
```cpp
std::cout << "文件名:" << p.filename() << std::endl;
```

### 获取后缀名
```cpp
std::cout << "文件后缀名:" << p.extension() << std::endl;
```

### 获取父目录
```cpp
std::cout << "文件父目录:" << p.parent_path() << std::endl;
```

### 判断文件是否存在
```cpp
if(std::filesystem::exists("project/myText.txt")){
    std::cout << "文件存在" << std::endl;
}else{
    std::cout << "文件不存在" << std::endl;
}
```
### 判断文件/目录
```cpp
if(std::filesystem::is_regular_file("myText.txt")){
    std::cout << "这是文件" << std::endl;
}
if(std::filesystem::is_directory("project")){
    std::cout << "这是目录" << std::endl;
}
```

### 获取文件大小
```cpp
std::cout << "文件大小:" << std::filesystem::file_size("myText.txt") << std::endl;
```

### 创建目录
```cpp
// 创建单层目录
std::filesystem::create_directory("logs");
// 创建多层目录
std::filesystem::create_directories("logs/projects/system");
```

### 删除文件/目录
```cpp
// 删除空目录/单文件
std::filesystem::remove("空目录/文件");
// 递归删除整个目录
std::filesystem::remove_all("目录");
```
### 复制文件
```cpp
std::filesystem::copy_file("文件A","文件B");
// 允许覆盖
std::filesystem::copy_file("文件A","文件B",std::filesystem::copy_options::overwrite_existing);
```

### 重命名文件
```cpp
std::filesystem::rename("old.txt","new.txt");
```

### 遍历目录
```cpp
for(const auto& entry : std::filesystem::directory_iterator(".")){
    if(entry.is_directory()){
        std::cout << "[DIR]" << entry.path() << std::endl;
    }
    else if(entry.is_regular_file()){
        std::cout << "[FILE]" << entry.path() << std::endl;
    }
}

### 递归遍历目录
```cpp
for(const auto& entry : std::filesystem::recursive_directory_iterator(".")){
    if(entry.is_directory()){
        std::cout << "[DIR]" << entry.path() << std::endl;
    }
    else if(entry.is_regular_file()){
        std::cout << "[FILE]" << entry.path() << std::endl;
    }
}
