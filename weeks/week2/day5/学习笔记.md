# constexpr
这个关键字告诉编译器可以在编译期求值，但是不强制编译期必须确定数值（编译期常量），这种情况下会退化成普通类型。

**核心思想**：尽量把能在编译阶段完成的事情提前完成。

### constexpr的使用场景
数组大小需要在编译期确定
* 不合法，未定义行为
```cpp
int getSize(){
    return 1024;
}

int arr[getSize()];
```
* 合法，在编译期确定
```cpp
constexpr int getSize(){
    return 1024;
}

int arr[getSize()]; // 编译器直接展开 int arr[1024];
```

### constexpr 成员函数
```cpp
struct Point{
    int x;
    int y;

    constexpr Point(int a, int b) : x(a), y(b){}

    constexpr int sum() const {
        return x + y;
    }
};

int x, y;
std::cin >> x;
std::cin >> y;
Point p(x,y);
p.sum();
```

### if constexpr
普通if: 运行时才决定A还是B
```cpp
if (条件)
{
    A;
}
else
{
    B;
}
```
if constexpr：编译时就决定A还是B
```cpp
if constexpr (条件)
{
    A;
}
else
{
    B;
}
```

**你现在其实已经掌握了 constexpr 最核心的 80% 内容：**

1. constexpr 变量必须在编译期确定值！！！
2. constexpr 函数不一定在编译期执行！！！
3. 只有参数是常量表达式时，constexpr 函数才可能在编译期计算。
4. 普通变量 int n = 5; 和编译期常量 constexpr int n = 5; 是两回事。

### 重复一下重点：
constexpr函数如果没有常数参数，可能会退化成普通函数，最终依然能通过编译
```cpp
// 是常量(成功编译)
int n = 10;

// 不是常量(成功编译)
int n;
std::cin >> n;

constexpr int factorial(int n)
```
constexpr变量必须拿到常量数值，不然无法通过编译，最终编译失败
```cpp
// 常量(成功编译)
constexpr int n = 10;

// 不是常量(编译失败)
constexpr int n;
std::cin >> n;
```
