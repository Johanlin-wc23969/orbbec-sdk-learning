# Structure Binding
目的是将多返回值的对象绑定到指定的变量上，让代码更简洁和易读
* 在这之前，我们读取pair<int,int>类型的对象，通过first和second
```cpp
std::pair<int,int> p = {1,10};

int a = p.first;
int b = p.second;
```
* 引入structure binding后
```cpp
std::pair<int,int> p = {1,10};

auto [a,b] = p;
```
### 使用场景：
* 拆解map类型的键值对
```cpp
unordered_map<int, std::string> mp = {{1,"johan"},{2,"oscar"},{3,"paulo"},{4,"alex"}};
for(auto [key,value] : mp){
    std::cout << "学号：" << key << " 名字：" << value << std::endl;
}
```
* 拆解pair类型
```cpp
std::pair<int, std::string> p = {1, "johan"};

auto [number, name] = p;
std::cout << "学号：" << number << " 名字：" << name << std::endl;
```
* 拆解tuple类型
```cpp
std::tuple<int, std::string, int> t = {1, "johan", 26};

auto [number, name, age] = t;
std::cout << "学号：" << number << " 名字：" << name << "年龄：" << age << std::endl;
```

### structure binding 的引用和拷贝
```cpp
unordered_map<int, std::string> mp = {{1,"johan"},{2,"oscar"},{3,"paulo"},{4,"alex"}};
```
* 拷贝
```cpp
for(auto [key,value] : mp){
    value++;
    std::cout << "学号：" << key << " 名字：" << value << std::endl;
}
```
* 引用
```cpp
for(auto& [key,value] : mp){
    value = 10; // 修改原始数据
}
```
* 只读引用
```cpp
for(const auto& [key,value] : mp){
    std::cout << "学号：" << key << " 名字：" << value << std::endl; // 只允许访问
}
```

### structure binding 支持的类型 （不支持vector和list，因为这些容器只有在运行时才能确定大小）
* pair
```cpp
std::pair<int,std::string> p = {1,"johan"}
auto [id,name] = p;
```
* tuple
```cpp
std::tuple<int,std::string,int> t = {1,"johan",26};
auto [id,name,age] = t;
```
* map
```cpp
std::map<int,std::string> mp = {{1"johan"},{2,"oscar"}}
for(auto [id,name] : mp){
    ...
}
```
* array
```cpp
std::array<int,3> arr = {1,2,3};
auto [a,b,c] = arr;
```
* struct
```cpp
struct Person{
    int age,
    std::string name,
}
Person p{26,"johan"};
auto [age,name] = p;
```
