# std::variant
当我们需要一个变量切换不同数据类型的时候，我们会使用union或者std::variant;
你大概会有个疑问，我们可以使用多态来解决这个需求，为什么还需要学习variant？
答：其实两者都能处理多个不同数据类型的场景，但是差别在具体的业务需求当中：
* 当业务确定了数据类型，以后不会再扩展增加新的数据类型，那么使用std::variant更加高效，因为是静态编译
* 当未来可能还会扩展增加其他数据类型，那么虚类的多态更适合和易于维护

### 为什么std::variant代替了union
因为union无法查看当前变量的数据类型，当尝试访问错误的非匹配类型会产生未定义行为，访问到垃圾数据。因此引入了std::variant代替union的不安全特性。

### 
* 创建实例
```cpp
#include <variant>

std::variant<int,std::string> data;
data = 10;
```
* 获取值 并执行对应的操作（主流）
```cpp
// 不同类型执行同一个函数
std::visit([](auto&& value){std::cout << value}, data);
// 不同类型执行不同函数 - overloaded（主流）
template<class... Ts>
struct overloaded : Ts...
{
    using Ts::operator()...;
};

template<class... Ts>
overloaded(Ts...) -> overloaded<Ts...>;

std::visit(
    overloaded{

        [](const LoginMsg& msg)
        {
            std::cout << "login "
                      << msg.username
                      << '\n';
        },

        [](const ChatMsg& msg)
        {
            std::cout << "chat "
                      << msg.content
                      << '\n';
        },

        [](const LogoutMsg&)
        {
            std::cout << "logout\n";
        }
    },
    data
);
```
* 获取值（可选）
```cpp
// 访问正确类型
auto result = std::get<int> (data)

// 访问错误类型
auto result = std::get<std::string> (data)
抛异常：std::bad_variant_access
```

* 安全获取值（可选）
```cpp
if(auto p = std::get_if<int>(data))
// 成功返回 *int，通过*p访问数据
// 失败返回 nullptr
```

* 判断类型（可选）
```cpp
if(std::holds_alternative<int>(data))
```
