# structure binding 结构化绑定
在结构绑定之前，人们总是需要通过访问对象或者实例的成员变量来获取特定数据。而使用结构绑定可以直接将对象的成员变量绑定到声明的新变量，让代码更加直观。
比如：
```cpp
std::unordered_map<int,int> mp;
// C++17之前
for(const auto m : mp){
    int key = m.first;
    int value = m.second;
}

// C++引入结构化绑定之后
for(const auto& [key,value] : mp){
    ...
}
```

# std::optional
在optional之前，人们需要通过-1或者NULL甚至""来表示异常情况，然而存在一些场景，-1或者空字符串依然代表合法的数据，此时就无法使用语法上合法的数值表示异常情况。而使用optional，对于异常情况，我们使用std::nullopt来表示，这样就避免了占用-1或者""的合法数值。
比如：
```cpp
std::optional<int> divide(int a, int b){
    if(b == 0) return std::nullopt;
    return a/b;
}
// 这种情况下 我们不需要额外在divide()之前先判断b是否为零，而是通过optional类型，在返回值上表示结果的合法性
```

# std::variant
在std::variant之前，人们使用union来让一个数据类型可以在不同的类型之间切换，但是union没有提供任何的安全性检查，而是直接通过访问变量，这就导致了当访问非当前类型的变量时，会把二进制解释成错误的类型。因此，为了避免这种潜在的bug，引入了variant代替union，并结合overloaded对不同类型执行不同代码逻辑，自动判断类型，避免手动访问错误的类型。
比如：
```cpp
template<class... Ts>
struct overloaded : Ts...{
    using Ts::operator()...;
}

template<class... Ts>
overloaded(Ts...)->overloaded<Ts...>;

std::variant<int,float,std::string> var;
std::visit(
    overloaded{
        [](int& value){std::cout << "This is Int\n"},
        [](float& value){std::cout << "This is float\n"},
        [](std::string& value){std::cout << "This is string\n"}
    },
    var
);
```
# std::filesystem 
c++17提供了直接操作文件系统的函数库
比如:
```cpp
// 创建path对象
std::filesystem::path p("文件路径");
// 文件名
p.filename();
// 文件后缀名 （包含.）
p.extension();
// 父目录
p.parent_path();

// 文件是否存在
std::filesystem::exists("文件路径");
// 判断是否是文件
std::filesystem::is_directory("文件路径");
// 判断是否是目录
std::filesystem::is_regular_file("文件路径");

// 查看文件大小
std::filesystem::file_size("文件路径");
// 创建目录
std::filesystem::create_directory("目录路径") // 创建文件是另一个库 std::ofstream file("文件名");
// 创建多级目录
std::filesystem::create_directories("多级目录路径")
// 删除文件/空目录
std::filesystem::remove("文件/空目录路径");
// 迭代删除目录
std::filesystem::remove_all("多级目录路径");

// 复制文件
std::filesystem::copy_file("旧文件名", "新文件名", std::filesystem::copy_options::overwrite_existing/*第三个参数可选*/);
// 文件重命名
std::filesystem::rename("旧文件名", "新文件名");

// 遍历目录
for(const auto& entry : std::filesystem::directory_iterator(".")){ // std::filesystem::recursive_directory_iterator(".") 迭代遍历目录
    // entry 是std::filesystem::directory_entry类型
    if(entry.is_directory()) std::cout << "This is directory\n";
    else if(entry.is_regular_file()) std::cout << "This is file\n";
}
```
# constexpr
为了提高性能，减少代码运行时开销，将可以提前编译的代码在编译期间完成，引入了constexpr
比如：
```cpp
// constexpr变量强制编译期确定数值
constexpr int n = 10;
// constexpr函数不强制要求编译期确定数值，可以退化成普通函数 在运行时计算数值。
// 编译期确定
constexpr int func(){
    return 1024;
}
// 退化成普通函数
int n;
std::cin >> n;
constexpr int func(int n){
    return n;
}
```
