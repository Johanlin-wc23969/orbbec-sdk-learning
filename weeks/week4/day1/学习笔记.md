# packaged_task
可以理解成把普通函数绑定到sharedState，实现了在多线程通过future获取结果。
`std::packaged_task<return_type(param_type)> task(func);`

| 工具                   | 你控制什么       | 典型用途            |
| -------------------- | ----------- | --------------- |
| `std::async`         | 直接启动任务      | 简单异步执行          |
| `std::promise`       | 手动设置结果      | 一个线程手动通知另一个线程   |
| `std::packaged_task` | 包装一个函数，稍后执行 | 任务队列、线程池、延迟启动任务 |


### 实例（packaged_task就是一个包装函数的类，把结果绑定在sharedState,提供了future接口获取返回值）：
```cpp
#include <thread>
#include <future>

int add(int a, int b){
    return a + b;
}
int main(){
    std::packaged_task<int(int,int)> task(add);
    std::future<int> f = task.get_future();
    std::jthread t(std::move(task),10,20); // packaged_task也可以显式调用 task(10,20);
    std::cout << f.get();
}
```
### 封装
```cpp
int add(int a, int b){
    return a + b;
}

std::packaged_task<int(int,int)> task(add);
```
### 两种调用方式
* 显式调用
```cpp
task(10,20);
```
* 交给线程
```cpp
std::jthread t(std::move(task),10,20);
```

### 获取结果
```cpp
std::future<int> f = task.get_future();
int res = f.get();
```

### 流程
函数 add
   ↓
packaged_task 打包
   ↓
get_future() 取结果接收器
   ↓
thread 执行 task
   ↓
task 内部把返回值放入 shared state
   ↓
future.get() 取结果
