## auto 类型

### auto 使用场景
auto 的目的是为了在实际开发过程中避免编写冗长/模版复杂/迭代器类型
比如：
```cpp
// 冗长的迭代器类型
std::vector<int>::iterator it = vec.begin();

// 简洁的迭代器类型
auto it = vec.begin();
```
又或者：
```cpp
// 模版复杂的类型
std::unique_ptr<std::map<int, std::vector<int>>> map = make_unique<std::map<int, std::vector<int>>>();

// 简洁的类型
auto map = make_unique<std::map<int, std::vector<int>>>();
```
再或者：
```cpp
// 范围循环的复杂类型
for(vector<int> vector : vecs){
    ...
}

// 范围循环的简洁类型
for(auto &vector : vecs){
    ...
}
```
### auto 类型推导决策图

             auto xxx = expr
                    │
                    ▼
                expr 是什么类型？
                    │
     ┌──────────────┼──────────────┐
     │              │              │
     ▼              ▼              ▼

    int         int&         const int

     │            │               │
     ▼            ▼               ▼

    int          int             int

auto xxx = 拷贝一份expr的值 所以忽略约束性关键字 & 和 const


            auto& xxx = expr
                    │
                    ▼

           expr 类型必须保留
              const 和 &
                    │
                    ▼

        int        -> int&
        int&       -> int&
        const int  -> const int&

auto& xxx = 自动类型推导 + 引用（expr的别名）

### auto 记忆
``` cpp
// 我要拷贝:     
auto a = expr;

// 我要引用:     
auto &a = expr;

// 我要只读引用:  
auto const &a = expr;

// 我要移动语义:  
auto&& a = expr
```

## decltype 类型

### decltype 使用场景
decltype 是模版和范型编程，用于推导表达式的类型，不需要知道具体类型的情况，但是需要知道原本的声明类型

代表变量的声明类型，不是单纯的赋值操作（auto）

### decltype 类型规则
```cpp
int x = 0;
```
情况1(不加括号):
```cpp
decltype(x) y = x; -> int y = x;
```
decltype(x) 的类型就是 x 的声明类型

情况2(加括号):
```cpp
decltype((x)) y = x; -> int &y = x;
```
decltype((x)) 的类型是 x 的表达式类型 也就是 x 本身（引用）

情况3(加括号+表达式):
```cpp
decltype((x+1)) y = x+1; -> int y = x+1;
```
此时x+1是一个右值，已经不是 x 了, 因此这个表达式的类型是int 而不是x（引用）

### decltype 理解技巧
decltype(x) 问的是 x 这个变量的类型是什么 ，这个时候指的是x的声明类型 int
decltype((x)) 问的是 x 这个表达式的类型是什么，这个时候指的是x本身是什么 因此是int&（引用）
