# Move Semantics & Rvalue Reference

### 左值和右值
```cpp
int a(左值) = 10(右值);
```
左值：有名字，有地址
右值：临时对象，不能长期存在


### 什么是右值引用&&？
&绑定左值
- example1
```cpp
int a = 10;
int& ref = a
```
- example2
```cpp
void func(int& x){
    std::cout << "it is lvalue\n";
}

func(x);
```
&&绑定右值
- example1
```cpp
int&& r = 10;
```
- example2
```cpp
void func(int&& x){
    std::cout << "it is rvalue\n";
}

func(std::move(x));
func(10);
```

### 为什么需要右值引用&&？
避免拷贝
```cpp
class Buffer
{
private:
    int* data;

public:
    Buffer(int size)
    {
        data = new int[size];
    }

    ~Buffer()
    {
        delete[] data;
    }
};
```
拷贝：
```cpp
Buffer b1(1000);
Buffer b2 = b1; // 申请新内存 复制全部数据
```
移动：
```cpp
Buffer b1(1000);
Buffer b2 = std::move(b1); // 更换指针 转移拥有权
```
### std::move 的本质
std::move()其实就是static_cast<T&&>，把左值转换成右值，触发移动构造，避免拷贝构造
```cpp
std::move(T obj) -> return static_cast<T&&>(obj);
```

### 移动构造
```cpp
class Buffer{
public:
    int* data;
    // 移动构造
    Buffer(Buffer&& other){
        // 获取对方data的指针
        data = other.data;
        // 置空对方data的指针
        other.data = nullptr;
    }
}
```

### 移动赋值
```cpp
class Buffer{
public:
    int* data;
    int size;
    // 移动赋值
    Buffer& operator= (Buffer&& other) {
        size = other.size;
        other.size = 0;

        if(data != nullptr){
            delete[] data;
        }

        data = other.data;
        other.data = nullptr;

        return *this;

    }
}
```

### Rule of five
```cpp
// 析构
~Buffer();
// 拷贝构造
Buffer(const Buffer& other);
// 拷贝赋值
Buffer& operator=(const Buffer& other);
// 移动构造
Buffer(Buffer&& other);
// 移动赋值
Buffer& operator=(Buffer&& other);
```

### 区分构造还是赋值
```cpp
Myclass a = Myclass("johan");
```
拷贝构造:
```cpp
Myclass b = a;
```
拷贝赋值:
```cpp
Myclass b;
b = a;
```
