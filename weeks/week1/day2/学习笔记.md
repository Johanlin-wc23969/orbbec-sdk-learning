# Lambda

### Lambda 使用场景
写在代码里的匿名函数，避免在全局完整定义
配合STL的algorithm算法

### Lambda 结构
```cpp
[捕获](参数){ 
    // 函数体
};
```

### 使用案例
配合STL排序算法等使用
```cpp
std::sort(vec.begin(), vec.end(), [](int a, int b){ return a > b; });
```
捕获使用
```cpp
int x = 10;

auto func = [x](){
    std::cout << x;
};

func();

x值捕获可以替换成
- 引用捕获&x
- 全部捕获=
- 全部引用捕获&
```

### 捕获和参数一起使用 （在sort()，find()等算法函数中，规定要求制定数量的参数），我们将额外的变量以捕获的方式传进去
比如：
```cpp
int target = 6;
auto firstGreater = find_if(distances.begin(), distances.end(), [target](int d1){
    return d1 > target;
});
```

# Functor 伪函数

### Functor 使用场景
配合STL的algorithm算法 比如sort,find等

lambda的最初形态，后面为了简化定义 转而使用lambda

### 历史进程
普通函数(function) -> 伪函数(functor) -> 匿名函数(anoymous function)

第一代：函数指针
```cpp
bool cmp(int a, int b)
```
第二代：函数对象（伪函数）
```cpp
class cmp{
    bool operator() (int a, int b){}
}
```
第三代：匿名函数
```cpp
[](int a, int b){
    return a < b;
}
```
### functor 怎么演变成 lambda？
```cpp
class GreaterThanTargetWithMinimumValue{
private:
    int target
public:
    GreaterThanTargetWithMinimumValue(int target){
        self.target = target;
    }
    bool operator() (int x, int y){
        return abs(x-target) > abs(y-target);
    }
}

Greater great(target);
find_if(vec.begin(), vec.end(), great())
等价于
find_if(vec.begin(), vec.end(), [target](int x, int y){ return x > y});
``` 
## 目前主流用法
主流使用lambda代替functor作为算法比较器，更加简洁

STL库提供了常用的functor：
```cpp
std::less<int>
std::greater<int>
std::plus<int>
std::minus<int>

std::sort(v.begin(), v.end(), std::greater<int>());
```
