# perfect forwarding
包装函数会将临时对象在转发过程中转换成左值对象，导致丢失了原本的右值状态。

因此需要完美转发在过程中保留原始右值状态，确保最终参数是作为右值传递。

完美转发实现了自动区分左值/右值参数并且确保转发过程中类型不转变。

换句话说：用一个模板同时代替无数个“左值版本+右值版本+多参数版本”的重载。

### Forwarding reference T&& 和 std::forward
```cpp
template<typename T>
void wrapper(T&& arg){
    print(std::forward<T>(arg));
}
```
传递左值
```cpp
wrapper("hello"); //传递左值参数
print(arg) // 到手就是左值
```
传递右值
```cpp
wrapper(std::string("hello")); //传递右值参数
// 原本这里会导致右值复制到arg变成左值，但是forward保留了原本的右值状态
print(arg) // 到手就是右值
```
### std::forward 做了什么
```cpp 
static_cast<T&&>(arg)
```

### push_back vs emplace_back （内部都实现了完美转发 可以根据参数左值右值类型来执行拷贝或移动）
push_back: 接受对象
```cpp
vec.push_back(std::string("johan"));
// 构造临时string
// ↓
// 移动到vector
// ↓
// 销毁临时string
```
emplace_back:接受对象和参数
```cpp
vec.emplace_back(”johan“);
// vec.emplace_back(s);               // T对象
// vec.emplace_back(std::move(s));    // T对象
// vec.emplace_back("hello");         // 构造参数
// vec.emplace_back(10, 'A');         // 构造参数
```
